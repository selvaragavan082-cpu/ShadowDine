# 🍽️ ShadowDine - Table Reservation & Food Pre-Ordering System

ShadowDine is a MERN stack web application that provides real-time restaurant table booking, food pre-ordering, and location-based nearby dining recommendations.

## ✨ Features
- 📍 **GPS & Google Maps Integration:** Nearby restaurant discovery with real-time location.
- 👤 **Customer & Admin Roles:** Role-based access and seamless authentication.
- 🥗 **Veg / Non-Veg Filtering:** Pure Veg & Non-Veg menu separation.
- 🛒 **Food Pre-Ordering Cart:** Select dishes and calculate total bill live.
- 🤖 **AI Food Assistant:** Get personalized dish recommendations.
- ⚙️ **Admin Management:** Add custom dishes with custom category names directly to live menu.

## 🛠️ Tech Stack
- **Frontend:** React.js, Axios, React Router
- **Backend:** Node.js, Express.js
- **Database:** MongoDB & Mongoose
- **APIs:** Google Places API / Nominatim Geocoding
